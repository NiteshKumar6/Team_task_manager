#  Team Task Manager

A full-stack MERN application to manage tasks, assign work, and track progress.

##  Features
- Create tasks
- Assign tasks
- Track status (Pending / Done)
- View all tasks

##  Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB

##  Run Locally

Backend:
cd backend
npm install
node server.js

Frontend:
cd frontend
npm install
npm start

##  Deployment
- Backend: Railway
- Frontend: Vercel
